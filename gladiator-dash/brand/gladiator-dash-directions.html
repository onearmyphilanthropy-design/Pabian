Gladiator Dash — mud run · Texas A&M · One Army

Three directions for a site built to text a friend from.

The core job of this site is a fast, mobile-first registration (ticket → heat → group → Apple Pay) and a group-invite page people actually forward. Each row below rebuilds the same three real screens — homepage hero, ticket selection, group invite — in a genuinely different visual language, for a college audience. Nothing here is decided; it's a reference set to react to.

01 Field Ops

Evolves the org's existing navy / cyan / red Instagram identity for the web — bold countdown-numeral type, gritty sports-marketing energy. The safest bet: it reads as "official Gladiator Dash" on sight to anyone who already follows the account.
