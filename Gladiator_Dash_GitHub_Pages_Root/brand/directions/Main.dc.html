Gladiator Dash — Visual Direction Exploration

Three directions, not one answer.

Each row below shows the same three real screens — homepage hero, ticket selection, and a group-invite share page — rebuilt in a genuinely different visual language. Nothing here is final; it's a reference set to react to.

FIELD OPS
Evolves the org's existing navy/cyan/red Instagram identity for the web. Bold countdown-numeral type, gritty sports-marketing energy — closest to "more of the same, done well."
MUD FEST
Raw, photocopied-flyer collage energy — stamps, tape, marker scribbles, halftone dots. Built to look native in a college group chat, not on a corporate site.
AGGIE VARSITY
Clean maroon-and-white athletics branding — jersey numerals, crest badge, varsity-program polish. Leans on campus pride rather than mud-run grit.
